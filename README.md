# All-Round Showcase

A local portfolio evidence repository for showcasing web apps, product design,
and implementation work through curated screenshots and capture manifests.

## Captures

### VCDocs — 3 September 2026

High-resolution desktop and mobile captures of the local VCDocs document-register
application. The capture includes:

- Overview dashboard
- Document register
- Client register
- Money and payment tracking
- Control room / administration
- Paid invoice detail
- Draft invoice editor

Open the route folders under
[`captures/vcdocs/2026-09-03`](captures/vcdocs/2026-09-03). Each route contains
desktop/mobile hero frames, sequential showcase frames, and a `manifest.json`.

The records visible in these screenshots are fictional demo clients and
transactions created in an isolated local archive for presentation purposes.

Issued presentation PDFs are available under
[`documents/vcdocs/2026-09-03`](documents/vcdocs/2026-09-03): one framework
contract, one proposal, and two invoices.

## Local source

The source application lives in the sibling `vcdocs` repository. This repository
contains showcase evidence only; it does not contain production client data.
